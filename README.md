## 常用 Git 命令

| 命令 | 作用 |
| --- | --- |
| `git status` | 查看当前状态 |
| `git add .` | 暂存所有改动 |
| `git commit -m "说明"` | 提交改动 |
| `git push` | 推送到远程仓库 |
| `git pull` | 拉取远程更新 |
